Area and Grid Reference — How to Locate Places on a Topographic Map

This NSW Education lesson teaches one of the most important topographic-map skills: using four-figure area references and six-figure grid references to locate features accurately.

Area reference: locating a grid square

A four-figure area reference identifies a general square on the map. The vertical grid lines are called eastings and the horizontal lines are northings.

The order is always eastings first, then northings. A common memory rule is to move ‘along the corridor and up the stairs’. The two easting digits and two northing digits identify the lower-left corner of the required grid square.

Using the map legend

Once the correct square has been found, the feature must still be interpreted. Topographic maps use colours, symbols and line styles to represent roads, vegetation, buildings, water bodies and other features.

The legend is therefore part of the locating process. A reference tells you where to look; the legend helps tell you what is there.

Grid reference: increasing precision

A six-figure grid reference identifies a more exact position. The same easting and northing lines are used, but the map reader estimates tenths within the grid square.

For the easting, the first two digits identify the grid line and the third digit estimates how far across the square the point lies. The same method is then used for the northing.

Why the skill matters

Grid referencing is not only an examination technique. It is a spatial communication system. It allows different people to identify the same feature accurately and provides a foundation for distance calculations, fieldwork, cross-sections and navigation.
