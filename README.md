# Pollution Explorer — Detailed Interactive Guide

A source-backed GitHub Pages educational site covering:

- Air pollution
- Water pollution
- Soil pollution
- Noise pollution
- Light pollution
- Visual pollution

For every pollution type the site includes:

- Definition
- How it spreads or moves
- Main subtypes
- Environmental impacts
- Wildlife impacts
- Human impacts
- Real-world examples
- Significant dated statistics
- Country or regional information
- Detailed solutions
- Linked sources
- Interactive comparison table
- Interactive quiz

## Run locally

Open `index.html` in any modern browser.

## Publish on GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

## Data note

Statistics are dated because estimates change. Visual pollution has no universally standardized global measurement method, so this project avoids claiming a worldwide ranking and instead uses a systematic research review and the São Paulo Clean City Law as examples.
